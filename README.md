## Getting Started

Clone the repository:

```bash
git clone https://github.com/mizanurmillon/mizanurmillon.git
cd mizanurmillon
```

Open the project or a specific folder and follow that project's README for setup and run instructions. Most web projects use the common commands:

```bash
# install dependencies
npm install
# run development server
npm run dev
# build for production
npm run build
```
